# Ruby's Minecraft Beta Archive
A collection of resources for Minecraft Beta 1.7.3 or recreating the Beta Experience in Modern Versions.

---
- **Option 1 -> Beta 1.7.3** — Playing the original Beta 1.7.3 version of the game (Recommended)
- **Option 2 -> Modern Beta** — Using mods and texture packs on modern Minecraft to replicate the Beta look and feel
  
## How to Use

1. Choose either **Beta 1.7.3** or **Modern Beta**
2. Install a Launcher (Prism Launcher is Recommended!)
3. Install the Appropriate Modloader for your Version!
4. Add any Mods or Texture Packs you may want!
